============================================================
AQ. NON-NEGOTIABLE EXECUTION RULE
============================================================

Do not stop after modifying source code.

For every defect:

1. Identify root cause.
2. Modify the minimum necessary code.
3. Add regression coverage.
4. Run the regression.
5. Verify runtime behavior.
6. Collect evidence.
7. Classify evidence correctly.
8. Report any remaining gap.

A feature is "FIXED" only when:

implementation exists
AND
regression coverage exists
AND
the relevant runtime verification passes.

A feature is "VERIFIED" only when the required evidence class has actually been collected.

If a test could not be executed, report:

UNVERIFIED — TEST NOT RUN

If runtime behavior could not be demonstrated, report:

UNVERIFIED — RUNTIME EVIDENCE MISSING

Never infer success from source inspection alone.
